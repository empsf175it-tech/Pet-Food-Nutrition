# PetFuel — Pet Food & Nutrition

GitHub Pages-ready static website.

## Upload
1. Upload `index.html` and the `assets` folder to your repository root.
2. Enable GitHub Pages from **Settings → Pages**.
3. Select the branch/root folder.

## Included
- Responsive PetFuel pet food & nutrition website
- Premium bespoke "Vitality Fuel Paw" brand emblem (`assets/petfuel-logo.svg`)
- Full vector brand lockup with modern typography (`assets/petfuel-brandmark.svg`)
- Matching high-contrast vector favicon (`assets/favicon.svg`)
- Floating smooth scroll-up button with scroll detection
- Animated live-order GIF
- Right-side image reveal sections
- Mobile/tablet/desktop responsive layout
- Zero external image/icon runtime dependencies
